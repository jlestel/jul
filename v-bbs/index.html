The three ideas

1

Plug in anything.

Run a model, or route to a server. Same Choice / Noul / Score calls, same response, whatever answers.

Hugging FaceKev modelsLayaEncoders · ONNX OllamaOpenAIMistralJevClefyour fine-tune

2

Great by default.

No model to pick, no prompt to write, no layer to choose. jul setup downloads a model picked and calibrated for typed questions: probabilities you can threshold on.

model="accurate"   # the default
model="fast"       # half the size

3

Autotune the rest.

Give it labeled examples: a small head is trained in seconds, kept only if it beats the default on examples it never saw. The model is untouched, calls stay as fast.

jul autotune tickets \
  --questions questions.yaml \
  --labeled labeled.jsonl

Your model, your hardware, your way out.

1 · MODEL

What reads it

  • accuratethe default model
  • fasthalf the size
  • any Hugging Face modeljul models add
  • a small encodere5, BERT, XLM-R
  • an embeddings APIOllama · OpenAI · Mistral · Voyage
  • Layaits own runtime

2 · HARDWARE

Where it runs

  • autoMLX on a Mac, PyTorch elsewhere
  • Apple SiliconMLX
  • NVIDIA GPUPyTorch · CUDA
  • CPUPyTorch, or ONNX without torch
  • no weights at all--backend api

3 · YOUR DATA

How it fits

  • zero-shotnothing to give
  • a Context~50 unlabeled examples
  • autotunelabeled examples, kept if it wins
  • jul synthtoo few labels? synthesize them

4 · INTEGRATION

How you call it

  • Pythonthe Jev SDK calls
  • the CLIjul ask · jul run
  • HTTPjul serve, the Jev protocol
  • a Lambdajul pack

Who gets the rest

  • nobodyeverything stays local
  • JevTypeSafe, hosted
  • Clef · Nimblecloudflare · ollama

MEASURE

        

          
Pit models against each other on your own rows: local ones, Jev, Ollama, a Kev server. One verdict: the fastest that is as good as the best.

          
jul bench test.jsonl --models fast,accurate,typesafe

        

      

      

        
ESCALATE

        

          
Answer locally, send only the unsure questions to a bigger decider. Each answer says which tier gave it.

          
jul serve --escalate-to typesafe

Two lines · on PyPI

      
Up in one coffee.

    


$ pip install jul
$ jul setup

    
Picks the backend (MLX on Apple Silicon, PyTorch elsewhere), downloads the model once, runs one real decision.

    

      No terminal handy? Let an agent do it.
      
    


Install jul (https://pypi.org/project/jul/), a local library that answers typed questions
with a small local model, and check that it works on this machine.

1. Create a virtualenv with Python >= 3.10.
2. In that venv: pip install jul   then   jul setup
   jul setup picks the backend (MLX on Apple Silicon, else PyTorch), installs it, downloads
   the default model once and runs one test decision.
3. Then run:
   jul ask choice "Which team should handle this ticket?" -o billing:"payments, invoices" -o technical:"bugs, errors" --state "I was charged twice"
   and show me the JSON.

Do not use sudo and do not install anything outside the venv. If a step fails, show me the error and
what you suggest before trying something else. At the end, tell me in two lines: the backend, the
latency per decision, and the answer to the ticket.
